# Conclusion

This project demonstrated the potential and limitations of deep learning approaches for automated diabetic retinopathy detection. While EfficientNet-B4 achieved superior quantitative performance, GradCAM analysis revealed some interpretability issues with all models. Additionally, the universal struggle with severe cases across all models highlights a critical gap between algorithmic performance and clinical needs. This emphasizes how positive initial results, like a high QWK, can be misleading if they do not fully encapsulate what is necessary for the problem, such as detecting severe cases.

The results underscore that model selection for medical AI requires balancing quantitative metrics with interpretability and clinical appropriateness. Future work must prioritize addressing class imbalance, improving severe case detection, and developing more clinically interpretable architectures.
